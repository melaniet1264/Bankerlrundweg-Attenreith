BANKERL-RUNDWEG ATTENREITH – MUSTER V6

Plauderbankerl mit vollständigem Inhalt aus dem Word-Dokument.
Vor dem Lösen des Rätsels ist der Geheimzahl-Pass vollständig leer.
Auch der Bereich „Weiter geht’s / Panoramabankerl“ ist zunächst verborgen.

Ablauf:
1. Antwort auswählen.
2. „Antwort prüfen“ drücken.
3. Bei einer falschen Antwort erscheint nur ein Hinweis zum erneuten Versuchen.
4. Bei A – Erdäpfel wird die Antwort als richtig bestätigt.
5. Erst dann wird Geheimzahl 5 in Feld 1 des digitalen Passes eingetragen.
6. Erst dann erscheint der Bereich zum Panoramabankerl.

Zum Testen: index.html oder plauderbankerl.html im Browser öffnen.
Für GitHub Pages alle Dateien gemeinsam in das Repository hochladen.
