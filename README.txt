BANKERL-RUNDWEG ATTENREITH – GEMEINSAME VERSION V10

Diese Version enthält beide Runden auf EINER Website:
- normale Rätselrunde
- Kinder-Rätselrunde

Die Startseite fragt nach der gewünschten Runde und speichert die Auswahl lokal im Browser.
Die QR-Code-Adressen bleiben einfach, z.B. /plauderbankerl.html. Wenn bereits eine Runde gewählt wurde, wird automatisch auf die passende Unterseite weitergeleitet. Sonst erscheint direkt eine Auswahl.

Testnavigation:
In erwachsene/app.js und kinder/app.js steht SHOW_TEST_NAV = true. Vor der endgültigen Veröffentlichung in BEIDEN Dateien auf false setzen.
